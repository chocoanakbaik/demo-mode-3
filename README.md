# Demo Mode 3 · TradePilot

Static trading-dashboard style template for ChocoScan browser-threat demonstrations. The interface uses fictional branding and illustrative market values.

All controls are local UI interactions only. No account or trading service is connected, and no personal information is sent or saved.

## Deploy manually to Netlify
1. Download this repository as a ZIP and extract it.
2. In Netlify, choose manual deploy.
3. Drag the extracted project contents into the deploy area. Keep `index.html`, `assets/`, and `netlify.toml` together.

## Files
- `index.html`: page layout
- `assets/css/style.css`: responsive design
- `assets/js/app.js`: local-only demo interactions
- `assets/favicon.svg`: tab icon
- `netlify.toml`: static publishing settings
